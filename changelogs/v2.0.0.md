## Change Log for Cuboid Outpost: Splendor Edition 2.0.0

Splendor Edition is a fork of Cuboid Outpost (Luxury Edition) 1.1.2. The quests and storyline are the same; this release rebalances progression and fixes long-standing pack bugs.

### Changes Made / Issues Fixed

- **Renamed** to Cuboid Outpost: Splendor Edition (window title, quest book title, server start scripts).
- **Sieving rebalanced to follow the quest line** (details: `docs/balance/sieve-progression.md`):
  - The Emerald Mesh now also needs 2 Osmium Ingots. Before, it was reachable straight after the first iron, which handed out osmium from gravel and let you skip the Smeltery, Getting Immersed and most of the route into Mekanism.
  - Osmium from gravel is now Emerald/Netherite Mesh only, at lower rates. Uranium moved from the Iron Mesh to Emerald/Netherite.
  - Upper-mesh bonuses are lower for every ore piece, diamonds, emeralds, nether quartz and uraninite. The very first tiers (Flint Mesh metals) are unchanged, so the start plays the same.
  - The Molecular Recycler no longer returns osmium.
  - Quest text (English and Italian) updated to match; the uranium appendix entry moved to the Emerald Mesh.
- **Spice of Life rebalanced**: 1 heart per milestone, up to **20 extra hearts** (40 total). The number of new foods needed per heart rises each tier of five hearts: 4, 6, 8, then 12 (150 unique foods for all 20).
  - `defaultconfigs` only applies to **new worlds**. For an existing world, copy `defaultconfigs/solcarrot-server.toml` over `<world>/serverconfig/solcarrot-server.toml` while the game/server is stopped.
- **Quantum singularities**: added the 8 missing singularity configs (bronze, diamond, electrum, emerald, invar, platinum, steel, uraninite) that the mod was warning about and falling back on.
- **Platinum and Storage Drawers tags now apply**: the tag script lived in `startup_scripts`, where KubeJS never fires tag events, so its tags (platinum block/nugget, full/half drawer tags) never existed. That also broke the platinum nugget → ingot recipe.
- **Install fixes**: TwerkItMeal was removed from CurseForge, and the pinned Configured file was deleted, so a fresh install of 1.1.2 failed to download both. Configured is updated; TwerkItMeal is dropped (nothing in the quests used it).
- Cleanup: removed the stale quest backup (`quests.bak`), KubeJS example assets and tag dumps, the unused LE overlay folder and a template backup.

### Mods Added

- **Essential** - 1.5.2 (Forge 1.16.5), client-side only
- **Essentialized** - 1.0.0, ported to Forge 1.16.5 / Java 8 for this pack (built from `mods-src/essentialized`, bundled in `overrides/mods`), client-side only. It turns off Essential's shop, purchases, coin dialogs, cosmetics, emotes, sale notices and the wardrobe, pictures and account menu buttons and player preview. Options are in `config/essentialized.json`.
